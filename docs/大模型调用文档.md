## [​](https://docs.laozhang.ai/api-reference/chat-completions\#%E6%8E%A5%E5%8F%A3%E7%AE%80%E4%BB%8B)  接口简介

Chat Completions 是老张API最核心的接口，用于与AI模型进行对话交流。支持200+AI模型，包括OpenAI、Claude、Gemini、DeepSeek等所有主流大模型。

## [​](https://docs.laozhang.ai/api-reference/chat-completions\#%E6%8E%A5%E5%8F%A3%E4%BF%A1%E6%81%AF)  接口信息

**接口地址**：`POST https://api2.laozhang.ai/v1/chat/completions`**兼容性**：完全兼容OpenAI官方API格式

## [​](https://docs.laozhang.ai/api-reference/chat-completions\#%E8%AF%B7%E6%B1%82%E5%8F%82%E6%95%B0)  请求参数

### [​](https://docs.laozhang.ai/api-reference/chat-completions\#%E5%BF%85%E9%9C%80%E5%8F%82%E6%95%B0)  必需参数

| 参数       | 类型   | 说明                                                         |
| ---------- | ------ | ------------------------------------------------------------ |
| `model`    | string | 要使用的模型名称，参考 [模型列表](https://docs.laozhang.ai/api-reference/models) |
| `messages` | array  | 对话消息数组，包含角色和内容                                 |

### [​](https://docs.laozhang.ai/api-reference/chat-completions\#%E5%8F%AF%E9%80%89%E5%8F%82%E6%95%B0)  可选参数

| 参数                | 类型         | 默认值 | 说明                     |
| ------------------- | ------------ | ------ | ------------------------ |
| `temperature`       | number       | 1.0    | 控制输出随机性 (0.0-2.0) |
| `max_tokens`        | integer      | 无限制 | 最大输出token数          |
| `top_p`             | number       | 1.0    | 核采样参数 (0.0-1.0)     |
| `frequency_penalty` | number       | 0.0    | 频率惩罚 (-2.0-2.0)      |
| `presence_penalty`  | number       | 0.0    | 存在惩罚 (-2.0-2.0)      |
| `stop`              | string/array | null   | 停止生成的标识符         |
| `stream`            | boolean      | false  | 是否流式输出             |
| `n`                 | integer      | 1      | 生成的选择数量           |
| `user`              | string       | null   | 用户标识符               |

## [​](https://docs.laozhang.ai/api-reference/chat-completions\#%E6%B6%88%E6%81%AF%E6%A0%BC%E5%BC%8F)  消息格式

### [​](https://docs.laozhang.ai/api-reference/chat-completions\#%E5%9F%BA%E7%A1%80%E6%B6%88%E6%81%AF%E6%A0%BC%E5%BC%8F)  基础消息格式

```
{
  "role": "user",
  "content": "你好，请介绍一下你自己"
}
```

### [​](https://docs.laozhang.ai/api-reference/chat-completions\#%E6%94%AF%E6%8C%81%E7%9A%84%E8%A7%92%E8%89%B2%E7%B1%BB%E5%9E%8B)  支持的角色类型

- **`system`**：系统消息，用于设置AI的行为和角色
- **`user`**：用户消息，用户的输入内容
- **`assistant`**：助手消息，AI的回复内容
- **`function`**：函数消息（OpenAI模型支持）
- **`tool`**：工具消息（部分模型支持）

### [​](https://docs.laozhang.ai/api-reference/chat-completions\#%E5%A4%9A%E6%A8%A1%E6%80%81%E6%B6%88%E6%81%AF%E6%A0%BC%E5%BC%8F)  多模态消息格式

对于支持图片理解的模型（如GPT-4o、Gemini Pro Vision），可以发送包含图片的消息：

```
{
  "role": "user",
  "content": [\
    {\
      "type": "text",\
      "text": "这张图片里有什么？"\
    },\
    {\
      "type": "image_url",\
      "image_url": {\
        "url": "https://example.com/image.jpg"\
      }\
    }\
  ]
}
```

import OpenAI from 'openai';

const openai = new OpenAI({
  apiKey: 'YOUR_API_KEY',
  baseURL: 'https://api2.laozhang.ai/v1'

async function chatCompletion() {
  const completion = await openai.chat.completions.create({
    model: 'gpt-4o-mini',
    messages: [\
      {\
        role: 'system',\
        content: '你是一个专业的AI助手，请用中文回答问题。'\

}

chatCompletion();

```
package main

import (
    "context"
    "fmt"
    "github.com/sashabaranov/go-openai"
)

func main() {
    config := openai.DefaultConfig("YOUR_API_KEY")
    config.BaseURL = "https://api2.laozhang.ai/v1"

    client := openai.NewClientWithConfig(config)

    resp, err := client.CreateChatCompletion(
        context.Background(),
        openai.ChatCompletionRequest{
            Model: openai.GPT4oMini,
            Messages: []openai.ChatCompletionMessage{
                {
                    Role:    openai.ChatMessageRoleSystem,
                    Content: "你是一个专业的AI助手，请用中文回答问题。",
                },
                {
                    Role:    openai.ChatMessageRoleUser,
                    Content: "请介绍一下老张API平台的特色功能",
                },
            },
            Temperature: 0.7,
            MaxTokens:   500,
        },
    )

    if err != nil {
        fmt.Printf("Error: %v\n", err)
        return
    }

    fmt.Println(resp.Choices[0].Message.Content)
}
```

### [​](https://docs.laozhang.ai/api-reference/chat-completions\#%E5%93%8D%E5%BA%94%E5%AD%97%E6%AE%B5%E8%AF%B4%E6%98%8E)  响应字段说明

| 字段      | 类型    | 说明                              |
| --------- | ------- | --------------------------------- |
| `id`      | string  | 请求的唯一标识符                  |
| `object`  | string  | 对象类型，固定为`chat.completion` |
| `created` | integer | 创建时间戳                        |
| `model`   | string  | 使用的模型名称                    |
| `choices` | array   | 生成的选择数组                    |
| `usage`   | object  | token使用情况统计                 |

### [​](https://docs.laozhang.ai/api-reference/chat-completions\#finish_reason-%E5%8F%96%E5%80%BC)  finish\_reason 取值

- **`stop`**：自然结束
- **`length`**：达到max\_tokens限制
- **`content_filter`**：触发内容过滤
- **`function_call`**：调用函数（OpenAI模型）
- **`tool_calls`**：调用工具（部分模型）

## [​](https://docs.laozhang.ai/api-reference/chat-completions\#%E6%B5%81%E5%BC%8F%E5%93%8D%E5%BA%94)  流式响应

设置 `"stream": true` 可以启用流式响应，实时获取生成内容：

cURL

Node.js

Python

```
curl https://api2.laozhang.ai/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "gpt-4o-mini",
    "messages": [\
      {"role": "user", "content": "写一首关于AI的诗"}\
    ],
    "stream": true
  }'
```

```
const stream = await openai.chat.completions.create({
  model: 'gpt-4o-mini',
  messages: [\
    { role: 'user', content: '写一首关于AI的诗' }\
  ],
  stream: true,
});

for await (const chunk of stream) {
  process.stdout.write(chunk.choices[0]?.delta?.content || '');
}
```

```
stream = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[\
        {"role": "user", "content": "写一首关于AI的诗"}\
    ],
    stream=True
)

for chunk in stream:
    if chunk.choices[0].delta.content is not None:
        print(chunk.choices[0].delta.content, end="")
```

### [​](https://docs.laozhang.ai/api-reference/chat-completions\#o1-%E7%B3%BB%E5%88%97%E6%8E%A8%E7%90%86%E6%A8%A1%E5%9E%8B)  O1 系列推理模型

O1系列模型专为复杂推理任务设计，不支持部分参数：

```
{
  "model": "o1-preview",
  "messages": [\
    {\
      "role": "user",\
      "content": "解决这个数学问题：如果一个数的平方等于64，这个数是多少？"\
    }\
  ]
}
```

O1系列模型不支持 `temperature`、`top_p`、`frequency_penalty` 等参数，也不支持 `system` 角色消息。

## [​](https://docs.laozhang.ai/api-reference/chat-completions\#%E4%BD%BF%E7%94%A8%E6%8A%80%E5%B7%A7)  使用技巧

### [​](https://docs.laozhang.ai/api-reference/chat-completions\#1-%E9%80%89%E6%8B%A9%E5%90%88%E9%80%82%E7%9A%84%E6%A8%A1%E5%9E%8B)  1\. 选择合适的模型

日常对话

- **推荐**：GPT-4o Mini、Claude 3.5 Haiku
- **特点**：响应快、成本低、质量好

代码生成

- **推荐**：GPT-4o、Claude 3.5 Sonnet、DeepSeek Coder
- **特点**：代码理解能力强、生成质量高

复杂推理

- **推荐**：O1 Preview、Claude 3 Opus
- **特点**：逻辑推理能力强、适合数学问题

中文处理

- **推荐**：通义千问、GLM-4、文心一言
- **特点**：中文理解和生成能力优秀

## [​](https://docs.laozhang.ai/api-reference/chat-completions\#%E8%AE%A1%E8%B4%B9%E8%AF%B4%E6%98%8E)  计费说明

老张API采用按Token计费模式，不同模型价格不同：

| 模型类型          | 输入价格        | 输出价格       | 特点         |
| ----------------- | --------------- | -------------- | ------------ |
| GPT-4o Mini       | $0.15/1M tokens | $0.6/1M tokens | 成本可控选择 |
| GPT-4o            | $5/1M tokens    | $15/1M tokens  | 多模态能力   |
| Claude 3.5 Sonnet | $3/1M tokens    | $15/1M tokens  | 推理能力强   |
| 通义千问 Turbo    | $0.3/1M tokens  | $0.6/1M tokens | 中文优化     |

实际费用以控制台显示为准。使用前请确保账户余额充足。

## [​](https://docs.laozhang.ai/api-reference/chat-completions\#%E6%9C%80%E4%BD%B3%E5%AE%9E%E8%B7%B5)  最佳实践

1. **使用合适的温度值**：创意任务使用0.7-1.0，精确任务使用0.1-0.3
2. **设置合理的max\_tokens**：避免无限制输出导致费用过高
3. **善用system消息**：设置清晰的角色和任务说明
4. **启用流式响应**：提升用户体验，实时显示生成内容
5. **错误重试机制**：实现指数退避重试策略
6. **监控使用情况**：定期检查控制台的使用统计
