# 分镜预览生成工作台重构 — 设计文档

日期：2026-08-12
状态：已批准（用户整体确认）
涉及仓库：AIStoryboardBackend（主后端）、AILLMGateway（LLM 网关）、AIStoryboardClient（前端）

## 1. 背景与目标

当前分镜列表卡片与预览面板职责混杂：列表卡片内嵌参考图上传（base64 存 soundDesign JSON）、参考图生图/生图生视频勾选框、生成/完善按钮与弹窗；预览面板同时承担结果展示与参考图控件。生成参数（模型/尺寸/质量/数量/时长/画幅）为全局 store，不分镜隔离；图片结果仅存单张 `imageUrl`；视频生成仅支持首帧图生视频，无参考视频/参考音频能力。

本次重构目标：

1. **分镜列表瘦身**：列表卡片不再出现参考图上传与「参考图生图/参考图生视频」勾选框；列表只保留提示词编辑与已知信息（剧本摘要、镜头标签、状态）查看。
2. **预览面板成为生成工作台**：图片 tab 只展示图片生成相关信息（模型/尺寸/质量/生成个数/参考图）；视频 tab 只展示视频相关信息（时长/分辨率/模型/画幅/参考图/参考视频/参考音频）。生成与完善入口全部移到预览面板。
3. **参数模型**：全局默认 + 分镜可单独覆盖（不覆盖时用全局值，覆盖后存该分镜）。
4. **参考素材全链路**：参考图/参考视频/参考音频真实上传、校验、参与生成（MiniMax-H3 多模态参考生视频 r2va）。
5. **范围一律经网关获取**：所有参数可选范围与上传约束来自网关 `/v1/models` 下发的模型 params，网关不可用时回退静态默认。

## 2. 技术事实（已核实）

- MiniMax-H3 `POST /v2/video_generation` 支持多模态 content 数组（`text` / `image_url` / `video_url` / `audio_url`），role 支持 `first_frame` / `last_frame` / `reference_image` / `reference_video` / `reference_audio`。
- **图生视频（first_frame/last_frame）与多模态参考（reference_*）互斥**，不可混用。
- 参考图 ≤ 9 张、单文件 ≤ 30 MB；参考视频 ≤ 3 个、单文件 ≤ 50 MB、单段 [2, 15]s、总时长 ≤ 15 s；参考音频 ≤ 3 个、单文件 ≤ 15 MB、单段 [2, 15]s；请求体总大小 ≤ 64 MB。
- 分辨率 768P / 2K；时长 4~15 整数秒；ratio 支持 adaptive / 21:9 / 16:9 / 4:3 / 1:1 / 3:4 / 9:16。
- 网关 `model_params` 表已具备约束列（ref_images_min/max、ref_videos_min/max、audio_count_min/max、audio_segment_duration_min/max、video_segment_duration_min/max、max_total_duration、max_total_files、max_video_size_mb、max_image_size_mb、max_audio_size_mb、max_request_body_mb、max_prompt_chars），`/v1/models` 组装已输出这些字段（`GatewayRoutingServiceImpl.buildParams` 的 `putRange` / `putInt`）。image 与 video 模型共用同一批列，image 模型填值后同样会下发。
- 网关当前视频契约仅透传 `imageUrl`（首帧），未透传参考素材；无文件上传代理。
- 主后端 `scene_reference_images` 表存在但未被使用（`SceneServiceImpl` 注入 `refImageMapper` 但未调用）。
- 前端参考图目前以 base64 存 `scenes.soundDesign` JSON（`getSceneRefs` / `setSceneRefs`），刷新丢失，将废弃。

## 3. 数据模型（主后端 PostgreSQL）

### 3.1 scenes 表新增列（参数覆盖 + 多图结果）

```sql
ALTER TABLE scenes
    ADD COLUMN image_urls TEXT,            -- 逗号分隔多图 URL（image_url 保留首图，兼容旧逻辑/Agent 链路）
    ADD COLUMN image_model VARCHAR(128),   -- 分镜覆盖：生图模型（null = 跟随全局默认）
    ADD COLUMN image_size VARCHAR(64),     -- 分镜覆盖：生图尺寸
    ADD COLUMN image_quality VARCHAR(32),  -- 分镜覆盖：生图质量
    ADD COLUMN image_n INT,                -- 分镜覆盖：生图个数
    ADD COLUMN video_model VARCHAR(128),   -- 分镜覆盖：视频模型
    ADD COLUMN video_aspect_ratio VARCHAR(32); -- 分镜覆盖：视频画幅（video_resolution / duration 已存在，直接复用）
```

覆盖语义：字段为 null 时生成采用全局默认值；预览面板中修改即写该分镜行（非 null 即覆盖）。提供「恢复全局默认」交互时置回 null。

### 3.2 参考素材表（改造 scene_reference_images）

现有表基本未用，改造为通用素材表：

```sql
ALTER TABLE scene_reference_images
    ADD COLUMN type VARCHAR(16) NOT NULL DEFAULT 'image', -- image / video / audio
    ADD COLUMN file_name VARCHAR(255),
    ADD COLUMN file_size BIGINT;            -- 字节
-- image_url 列复用，存储相对 URL（/api/files/references/{sceneId}/xxx）
```

每分镜的参考素材按类型分组存储，排序沿用 `sort_order`。前端上传后持久化到该表，刷新不丢。旧的 soundDesign JSON 参考图方案（`getSceneRefs` / `setSceneRefs`）废弃。

## 4. 网关改动（AILLMGateway）

### 4.1 视频创建契约扩展

请求体新增可选字段：

```json
{
  "model": "MiniMax-H3",
  "prompt": "...",
  "resolution": "768P",
  "duration": 8,
  "aspectRatio": "16:9",
  "imageUrl": "首帧 data URI 或 mm_file://（i2v 模式）",
  "referenceImages": ["data URI 或 mm_file://"],
  "referenceVideos": ["mm_file://"],
  "referenceAudios": ["mm_file://"]
}
```

`VideoGatewayServiceImpl.createMinimax` 组装 content 数组：

- 任一 `reference*` 数组非空 → 多模态参考模式：对应 role `reference_image` / `reference_video` / `reference_audio`；**此时不允许出现 imageUrl 首帧**（互斥，40001 报错）。
- 仅 `imageUrl` → 现有 i2v 首帧模式（role=first_frame）。
- 两者皆无 → t2v 纯文本模式。

### 4.2 文件上传代理

新增 `POST /v1/files/upload`（multipart：file）→ 转发 MiniMax 文件上传接口获取 `file_id` → 返回 `mm_file://{file_id}`。解决参考视频（50 MB）/参考音频（15 MB）/多参考图 base64 膨胀超出 64 MB 请求体限制的问题。鉴权沿用 `/v1/**` 的 StaticApiKeyFilter。

### 4.3 model_params

约束列已齐、组装已输出，网关后端零改动。admin-ui（独立仓库）需给 image 模型开放 refImages / maxImageSizeMB / maxRequestBodyMB 等录入项（用户侧操作，不在本计划实现范围，文档留档）。

## 5. 主后端改动（AIStoryboardBackend）

### 5.1 上传端点

`POST /api/scenes/{sceneId}/references`（multipart：`type` + `file`）：

- 校验：scene 归属、type ∈ {image, video, audio}、数量上限与单文件大小上限按所选模型网关约束（`GatewayModelService` 拉取的 params；网关不可用回退宽松默认：图 10 张/30 MB，视频 3 个/50 MB，音频 3 个/15 MB）。
- 存储：`uploads/references/{sceneId}/`，落 `scene_reference_images` 表（type / file_name / file_size / sort_order）。
- 返回：素材记录（id / type / url / fileSize）。
- 删除端点：`DELETE /api/scenes/references/{id}`。

### 5.2 generate-image 契约

- 响应支持 `imageUrls: string[]`（n > 1 时多张）；`imageUrl` 保留为数组首张，兼容现有前端与 Agent 链路。
- 落库 `scenes.image_urls`（逗号分隔）+ `image_url`（首张）。
- 图改图（mode=edit）沿用现有逻辑（源图 = generatedImageUrl 或参考图）。

### 5.3 generate-video 契约

请求体新增 `referenceImages[]` / `referenceVideos[]` / `referenceAudios[]`（数组，元素为 data URI 或 mm_file:// 或 http URL），透传网关。生成时文件读取与转换：

- 小文件（≤ 10 MB）读文件转 data URI 内联（沿用现有图生视频做法）；
- 大文件调网关 `/v1/files/upload` 换 `mm_file://`。
- 互斥：参考素材任一存在时不再传 imageUrl 首帧（「以本分镜图片为首帧」开关未开时）；业务侧保证。

### 5.4 生成参数优先级

用户提交（分镜覆盖值）> 全局默认（前端 store）> 模型默认（params）> 配置默认。`SceneRequest` / 生成请求 DTO 支持透传分镜覆盖参数。

## 6. 前端改动（AIStoryboardClient）

### 6.1 SceneCard 瘦身

移除：参考图上传、参考图生图/生图生视频勾选框、生成/完善按钮、ImageRefineModal / VideoRefineModal 入口。
保留：分镜名/重命名、删除、剧本摘要、镜头标签、**生图/生视频提示词编辑**、状态徽标（pending / generating+进度 / completed / failed）、未读红点、选中/动画。

### 6.2 PreviewPanel 生成工作台

**图片 tab**：

- 结果区：`image_urls` 多图**轮播**（首图为封面，圆点切换，点击放大灯箱）；**逐张勾选 + 批量下载**（fetch + blob 方式，沿用 `downloadAsset`）；生成中显示进度状态。
- 生成参数区：
  - 「参考图生图」勾选框 → 勾选后展开：生图模型下拉（网关 `imageModels`）+ 参考图上传（数量 ≤ params.refImages.max、单文件 ≤ params.maxImageSizeMB、累计 ≤ params.maxRequestBodyMB）+ 生成个数 n 滑块（params.n.min~max）+ 尺寸（params.sizes）+ 质量（params.qualities）。
  - 未勾选：仅模型 / 尺寸 / 质量 / n。
- 操作按钮：「生成」（按当前参数新生成，覆盖结果批次）、「完善」（以当前图片为源图图改图）。

**视频 tab**：

- 结果区：视频播放器 + 下载。
- 生成参数区：模型下拉（网关 `videoModels`）+ 时长（params.durations 范围，下拉或滑块）+ 分辨率（params.resolutions）+ 画幅（params.aspectRatios）+ 参考素材区（参考图 / 参考视频 / 参考音频三类上传，数量与单文件大小按 params 对应约束，展示剩余额度）+ 「以本分镜图片为首帧」开关。
- 互斥：开启首帧开关时禁用参考素材上传（r2va 与 i2v 互斥，与网关一致），反之亦然。
- 操作按钮：「生成」。视频「完善」语义不单设按钮——由「以本分镜图片为首帧」开关 + 参考素材 + 参数调整 + 生成覆盖（原 VideoRefineModal 的「当前图首帧 + 参考图」能力被完整覆盖）。

所有控件范围来自网关 params，缺失字段隐藏控件（零回归）。参数修改：写分镜覆盖列；「恢复全局默认」按钮置回 null。

### 6.3 store 与 API

- `projectStore`：`getSceneRefs` / `setSceneRefs`（soundDesign JSON）移除，改为分镜素材列表读写（后端接口）；新增分镜覆盖参数读写（scene 表列）；全局默认参数保留（现有 imageModel / videoModel / imageSize / imageQuality / imageN / videoPreset 拆分为 duration + aspectRatio 两态）。
- `api/scenes.ts`：上传参考素材 / 删除素材 / 更新分镜参数。
- `api/ai.ts`：generateImage 响应类型加 `imageUrls`；generateVideo 请求加 `referenceVideos` / `referenceAudios`。
- 场景参数选择 UI 可复用 `AgentParamSelector` 的 PARAM_META 解析思路（提取为共享工具函数）。

## 7. 校验与互斥

| 项 | 规则 |
|----|------|
| 素材类型 | image: image/*；video: video/mp4, video/quicktime；audio: audio/wav, audio/mpeg |
| 数量 | 按 params.refImages / refVideos / audioCount 范围，超出前端拦截 + 后端兜底 |
| 单文件大小 | 按 params.maxImageSizeMB / maxVideoSizeMB / maxAudioSizeMB |
| 请求体 | 素材累计 + base64 膨胀估算 ≤ params.maxRequestBodyMB |
| r2va / i2v | 参考素材与首帧互斥（前端 UI + 网关双重） |
| 提示词 | 长度 ≤ params.maxPromptChars（前端计数提示） |

视频/音频时长（2~15 s）前端用 metadata 预检拦截，上游 400 兜底。

## 8. 测试链路（必须做到位）

1. **后端编译**：`mvn compile -q`（JAVA_HOME 用 Windows 路径）。
2. **网关编译**：AILLMGateway `mvn compile -q`。
3. **网关冒烟**：起 8085 实例（SERVER_PORT env）+ 自签 JWT；`POST /v1/files/upload` 上传小文件返回 mm_file://；`POST /v1/videos` 带 referenceImages/referenceVideos/referenceAudios 契约解析正确（无上游密钥时以契约校验/桩响应验证组装逻辑）。
4. **主后端冒烟**：`POST /api/scenes/{id}/references` 上传三类素材、约束校验（数量/大小超限返回 40001）；generate-image n=4 返回 imageUrls；generate-video 透传参考素材。
5. **前端**：`npx tsc -p tsconfig.app.json --noEmit` + `npm run build`。
6. **手工链路**（浏览器）：列表无参考图控件 → 预览面板图片 tab 多图轮播 + 勾选下载 → 参考图生图真生成 → 视频 tab 参考素材上传约束展示 → 参考视频真生成一条（MiniMax 密钥可用时）→ 参数覆盖持久化（刷新不丢）。
7. **回归**：Agent 对话链路（图生视频走 /form/submit）不受 scenes 表新增列影响。

## 9. 范围外（留档）

- admin-ui（独立仓库）image 模型约束录入表单。
- 参考素材的时长/帧率等深度校验（上游兜底）。
- 视频多结果轮播（当前视频单条，`videoUrl` 保持单值）。
