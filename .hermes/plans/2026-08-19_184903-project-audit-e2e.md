# 全项目代码审计 + 全接口端到端测试 实施计划

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** 对 AI Storyboard 全栈（5 个模块 + 前端）做一次系统性代码审计（安全/分层规范/接口契约/配置），产出一份带严重级别的审计报告；随后搭建端到端测试套件，对每个 HTTP 接口按「正常/越权/非法参数」三类用例实测，产出通过/失败报告。

**Architecture:** 现状是 moon-agent 微服务迁移后的拓扑 —— ApiGateway(8080, Spring Cloud Gateway webmvc + Nacos) 按路径路由：`/api/agent/**` → MoonAgent(8084)，其余 → AIStoryboardBackend(8082)；AILLMGateway(8083) 提供 OpenAI 兼容 `/v1/**`(StaticApiKeyFilter) 与 `/admin/**`(AdminJwtFilter)；MoonAgent 通过共享 `internal.secret` 调主后端 `/api/internal/**`；前端 5173 开发环境 Vite proxy → 8080。审计以模块为单位、E2E 以网关 8080 为真实入口。

**Tech Stack:** Spring Boot 4 / JDK 21 / MyBatis-Plus / PostgreSQL / Spring Cloud Gateway / JWT(jjwt) / Spring AI 2.0 / React 19 + TS / Python 3(测试脚本, urllib 零依赖, 复用 scripts/ 既有模式)
