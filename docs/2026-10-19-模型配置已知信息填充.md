|---|---|---|
| `mimo-v2.5-tts-voicedesign` | video | 名称是 TTS/音色设计，不是视频模型；没有可靠的视频参数 |

建议先确认类型，再改 `model_params.type` 与对应 `model_route.type`，然后重跑脚本。

## 4. 注意事项

- text/vision 的 `temperature/top_p/max_tokens` 是 OpenAI 兼容通用参数，没有设置 `injectDefault`，不会强行改写请求；同时把固定列 `temperature=0.7`、`top_p=1` 补齐，保持老链路一致。
- `veo` 当前绑定的是 `laozhang` 的 `openai_compatible` 渠道，响应映射按通用 task 字段填；如果改成原生 Veo operation，需要适配器和 operation 路径。
- `MiniMax-H3` 的 `referenceImages` 使用 camelCase，和视频适配器的 `toCreateInput` 一致。
- 视频首帧统一用 `imageUrl`（`VideoGatewayServiceImpl.toCreateInput` 读取的字段），不能用 `image`，否则图生视频会被忽略。
- 所有 Schema 都通过 `/admin/model-params/validate` 后写入。
- 模型目录缓存由 `PUT /admin/model-params` 自动失效，无需重启。

## 5. 重跑

```powershell
python AILLMGateway/scripts/fill_known_model_params.py
```

脚本是幂等的：已有 Schema 且不在 `FORCE` 列表中的模型会跳过；只更新缺失或明确需要修正的模型。
