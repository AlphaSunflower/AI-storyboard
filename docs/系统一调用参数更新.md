# 系统一接入分镜系统——调用参数（更新版）

## 新增账号密码校验后，系统一需多传 2 个字段

### 调用参数

```
POST http://localhost:8082/api/auth/unlogin
Content-Type: application/json

{
  "account": "用户邮箱",
  "password": "用户明文密码",
  "jwt": "系统一的accessToken"
}
```

### 系统一后端代理路由更新

```javascript
// backend/api/src/modules/auth/auth.service.ts

async storyboardLogin(email: string, password: string, userJwt: string) {
  const resp = await axios.post(
    `${this.storyboardUrl}/api/auth/unlogin`,
    { account: email, password, jwt: userJwt },
    { timeout: 10000 }
  );
  // ...
}
```

### 系统一 Controller 更新

```javascript
// auth.controller.ts
async storyboardLogin(request, response) {
  const authenticated = await requireAuth(request, response, ...);
  if (!authenticated) return;

  const userJwt = request.headers.authorization.replace('Bearer ', '');

  // 从请求体读取 email + password（系统一前端传入）
  const body = await parseJsonBody(request); // 或 req.body
  const { email, password } = body;

  const result = await this.authService.storyboardLogin(email, password, userJwt);
  sendJson(response, 200, { code: 200, data: result });
}
```

### 系统一前端跳转按钮更新

```javascript
// 需要用户输入密码或从状态获取
async function goToStoryboard() {
  // 如果系统一存有用户密码，直接读取
  // 否则弹窗让用户输入
  const password = prompt('请输入您的密码以跳转到分镜系统：');
  if (!password) return;

  try {
    const res = await fetch('/api/v1/auth/storyboard-login', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        email: currentUser.email,  // 或从 store 获取
        password
      })
    });

    const data = await res.json();
    if (data.code === 200) {
      const { accessToken, refreshToken, userId, displayName } = data.data;
      window.open(
        `http://localhost:5173/?token=${encodeURIComponent(accessToken)}&refresh=${encodeURIComponent(refreshToken)}&userId=${encodeURIComponent(userId)}&name=${encodeURIComponent(displayName)}`
      );
    } else {
      alert(data.message || '跳转失败');
    }
  } catch {
    alert('网络错误');
  }
}
```

---

## 参数对照

| 字段 | 来源 | 说明 |
|------|------|------|
| `account` | 系统一用户邮箱 | 从 store/user info 获取 |
| `password` | 用户输入 | 系统一不存明文则弹窗获取 |
| `jwt` | 系统一 accessToken | 从 localStorage/cookie 获取 |
