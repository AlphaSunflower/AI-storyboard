# AI Agent 独立页面设计规格

## 概述

创建一个全新的 AI Agent 独立页面，采用双面板布局（左侧导航 + 右侧全屏对话），与现有编辑器页面并列。页面风格参考 Claude UI，遵守项目设计规范（Anthropic 暖色调编辑风格）。

## 设计规范

### 颜色系统

| Token | 值 | 用途 |
|-------|-----|------|
| Primary (coral) | `#cc785c` | 主按钮、强调色 |
| Canvas (cream) | `#faf9f5` | 页面背景 |
| Ink (dark) | `#141413` / `#181715` | 主文字 |
| Surface card | `#efe9de` | 卡片背景 |
| Hairline | `#e6dfd8` | 分割线 |
| Muted | `#6c6a64` | 次要文字 |

### 字体系统

- **Display**: Copernicus, Tiempos Headline, serif
- **Body**: StyreneB, Inter, sans-serif
- **Code**: JetBrains Mono, monospace

### 圆角

- 按钮/输入框: 8px
- 卡片: 12px
- Hero 区域: 16px

## 左侧导航

### 导航项

| 序号 | 图标 | 标签 | 点击行为 |
|------|------|------|---------|
| 1 | ➕ | 新对话 | 创建新会话，清空当前对话 |
| 2 | 🎬 | 分镜 | 打开浮动弹窗（分镜管理） |
| 3 | 🖼️ | 资产 | 打开浮动弹窗（资产库） |
| 4 | 📁 | 项目 | 打开浮动弹窗（项目切换） |
| 5 | ── | 分隔线 | 视觉分隔 |
| 6 | 💬 | 历史 | 折叠/展开历史对话列表 |
| 7 | ⚙️ | 设置 | 打开浮动弹窗（设置） |

### 历史对话列表

- 默认折叠，点击"历史"展开
- 显示最近 20 条对话（标题 + 时间）
- 点击切换到该对话
- 当前对话高亮

## 主对话区域

### 两种状态

#### 初始态（无对话）

- 中央显示欢迎文案："你好，有什么可以帮你的？"
- 输入框在底部固定

#### 对话态（有消息）

- 顶部标题栏：当前对话标题（可点击重命名）+ 分享按钮
- 中间：消息滚动区
  - 用户消息：右对齐，灰色气泡
  - AI 消息：左对齐，带 Logo 标识
- 底部固定：输入框 + 提示文案

### 输入框

- 左侧：`[+附件]` 按钮（上传图片/文件）
- 中间：文本输入区（placeholder: "输入消息..."）
- 右侧：`[发送]` 按钮（Primary 色）
- 下方提示："AI 可能会犯错，请核实重要信息。"

## 浮动弹窗

### 触发方式

从左侧导航菜单点击触发，覆盖在主区域上方。

### 弹窗类型

1. **分镜弹窗**：管理当前项目的分镜列表
2. **资产弹窗**：查看和管理生成的图片/视频资产
3. **项目弹窗**：切换和管理项目
4. **设置弹窗**：用户设置和偏好

### 弹窗样式

- 背景遮罩：半透明黑色
- 弹窗主体：白色卡片，圆角 12px
- 可拖拽标题栏
- 关闭按钮（右上角 X）
- 动画：fade + slide

## 数据流

### 状态管理

使用现有 `agentStore`（Zustand），扩展以下状态：

```typescript
interface AgentPageState {
  // 页面级状态
  sidebarCollapsed: boolean;
  activeModal: 'storyboard' | 'assets' | 'project' | 'settings' | null;
  
  // 对话相关（已有）
  conversations: AgentConversation[];
  activeConversationId: string | null;
  messages: AgentMessage[];
  streaming: boolean;
  // ...
}
```

### 路由

新增路由 `/agent`，与现有 `/editor` 并列：

```tsx
<Route path="/agent" element={<AgentPage />} />
```

## 复用现有组件

- `MessageBubble`：消息气泡
- `HumanInputCard`：HITL 输入卡片
- `ConfirmResultCard`：确认结果卡片
- `VideoPlanCard`：视频方案卡片
- `TextType`：打字机效果
- `agentStore`：状态管理
- `agentApi`：API 调用

## 已确认需求

### 1. 保留现有 Agent 抽屉

现有 `AgentDrawer` 组件保留不动，新页面与抽屉共存。

### 2. 分镜弹窗

分镜弹窗仅作为外链跳转：点击后打开当前项目对应的 AI 分镜网址，查看分镜导出情况。不需要内嵌分镜管理 UI。

### 3. 资产弹窗分页

资产弹窗支持分页，复用现有 `agentApi.getAssets(page, size)` 接口。

### 4. HITL 人工介入选项布局

Agent 触发人工介入（`human_input` 事件）时，选项按钮采用**一行一个**布局（垂直堆叠），而非横向排列：

```
┌──────────────────────────────┐
│ 请选择处理方式：               │
│                              │
│ ┌──────────────────────────┐ │
│ │ 基于现有分镜优化           │ │
│ └──────────────────────────┘ │
│ ┌──────────────────────────┐ │
│ │ 全新创建分镜               │ │
│ └──────────────────────────┘ │
│ ┌──────────────────────────┐ │
│ │ 不生成分镜                 │ │
│ └──────────────────────────┘ │
└──────────────────────────────┘
```
