# /editor 手机端适配实现计划（v2）

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** 编辑器页面适配手机端——复用 /chat 侧栏（项目/会话/设置），/editor 只负责分镜列表、预览、剧本输入。

**Architecture:** EditorPage 手机端 = 顶栏（☰ 菜单 + 项目名 + 📝剧本）+ 内容区（列表/预览切换）+ 底部 Tab 栏。☰ 打开 /chat 同款侧栏 overlay（MobileSidebarContent），📝 打开右侧剧本输入抽屉。不渲染 AppHeader / LeftSidebar / AgentFab / TaskFab。

**Tech Stack:** React 19, TypeScript, Zustand, inline styles

---

## 现有可复用组件

| 组件 | 作用 | 复用方式 |
|------|------|---------|
| `useIsMobile()` | ≤768px 检测 | 直接 import |
| `MobileSidebarContent` | /chat 侧栏（项目/资源库/会话/设置） | 直接 import，☰ 打开 |
| `MobileHeader` | ☰ \| 标题 \| ＋ | 不用——/editor 顶栏不同，新建 `MobileEditorHeader` |

| `ProjectDropdown` | 项目下拉 | 不需要——侧栏已有 |
| `AssetLibraryPanel` | 资产库面板 | 直接 import |

## Task 6: 改造 EditorPage 手机端分支

**Files:** Modify `src/pages/EditorPage.tsx`

```tsx
const isMobile = useIsMobile();
const [mobileView, setMobileView] = useState<'list' | 'preview'>('list');
const [sidebarOpen, setSidebarOpen] = useState(false);
const [scriptOpen, setScriptOpen] = useState(false);
const [assetsOpen, setAssetsOpen] = useState(false);

if (isMobile) {
  return (
    <div style={{ height: '100vh', display: 'flex', flexDirection: 'column' }}>
      <MobileEditorHeader onMenuClick={() => setSidebarOpen(true)} onScript={() => setScriptOpen(true)} />
      <div style={{ flex: 1, minHeight: 0, overflow: 'hidden' }}>
        {mobileView === 'list' ? (
          <MobileSceneList onSelectScene={(id) => { selectScene(id); setMobileView('preview'); }} />
        ) : (
          <MobileScenePreview onBack={() => setMobileView('list')} />
        )}
      </div>
      <MobileBottomNav onOpenAssets={() => setAssetsOpen(true)} />
      {/* overlays */}
      {sidebarOpen && <MobileSidebarOverlay onClose={() => setSidebarOpen(false)} />}
      {scriptOpen && <ScriptInputDrawer onClose={() => setScriptOpen(false)} />}
      {assetsOpen && <AssetLibraryPanel onClose={() => setAssetsOpen(false)} />}
    </div>
  );
}
```

MobileSidebarOverlay：封装 MobileSidebarContent + backdrop + 滑入动画（同 /chat 的侧栏模式）。
