# 系统一接入分镜系统操作指南

## 概述

系统一（Node.js）和分镜系统（Spring Boot）共享 `public.users` 表和 JWT 密钥。
用户在系统一登录后，点击跳转按钮即可无状态免密进入分镜系统。

## 原理

```
系统一前端 ──POST {jwt: 系统一accessToken}──→ 分镜系统 /api/auth/unlogin
                                                    │
                                                    ├── 验签JWT → 取userId
                                                    ├── 查用户 → 确认存在
                                                    ├── 签发新JWT（分镜系统密钥）
                                                    └── 返回 {accessToken, refreshToken, userId, name}

系统一前端 ←── {accessToken, ...} ────────────────┘
     │
     └── window.open('http://localhost:5173/?token=xxx&userId=xxx&name=xxx')
```

---

## 步骤 1：系统一后端新增代理路由

在系统一 Express 路由中新增 `/storyboard-login`：

```javascript
// routes/storyboard.js
const express = require('express');
const axios = require('axios');
const router = express.Router();

router.post('/login', async (req, res) => {
  try {
    // 从请求 Authorization 头取系统一的 JWT
    const userJwt = req.headers.authorization?.replace('Bearer ', '');

    if (!userJwt) {
      return res.status(401).json({ error: '未登录' });
    }

    // 调分镜系统交换 token
    const response = await axios.post(
      'http://localhost:8082/api/auth/unlogin',
      { jwt: userJwt },
      { timeout: 10000 }
    );

    res.json(response.data);
  } catch (err) {
    console.error('分镜系统登录校验失败:', err.message);
    res.status(401).json({ error: '登录校验错误' });
  }
});

module.exports = router;
```

## 步骤 2：系统一前端跳转按钮

```javascript
// 在系统一的页面中，添加"跳转分镜系统"按钮

async function goToStoryboard() {
  try {
    const res = await fetch('/storyboard/login', { method: 'POST' });
    const data = await res.json();

    if (data.code === 200) {
      const { accessToken, refreshToken, userId, displayName } = data.data;

      // 新标签页打开，URL 传参
      window.open(
        `http://localhost:5173/?token=${encodeURIComponent(accessToken)}&refresh=${encodeURIComponent(refreshToken)}&userId=${encodeURIComponent(userId)}&name=${encodeURIComponent(displayName)}`
      );
    } else {
      alert('跳转失败：' + (data.message || '登录校验错误'));
    }
  } catch (err) {
    alert('网络错误，请稍后重试');
  }
}
```

## 步骤 3（可选）：直连模式

如果不走系统一后端代理，前端直连分镜系统（需确保 CORS 已配置）：

```javascript
async function goToStoryboard() {
  const jwt = localStorage.getItem('accessToken');

  const res = await fetch('http://localhost:8082/api/auth/unlogin', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ jwt })
  });

  const data = await res.json();
  // ... 同上处理
}
```

---

## 生产环境调整

- `localhost:8082` → 分镜系统实际部署地址
- `localhost:5173` → 分镜系统前端实际地址
- 如果两套系统同域，可改用 cookie 传递 token（更安全）
