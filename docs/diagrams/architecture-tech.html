分镜智能创作平台 · 系统架构

分层视图 · 含智能编排、沙箱执行面与产物沉淀链路
统一部署栈 十三个容器 · 六层结构
全部模型调用经统一网关
01
客户端层
面向创作者的三类入口，共用同一套鉴权与创作上下文

Web 分镜编辑器 主入口

剧本输入、分镜列表、预览与生成，内置智能体对话面板

  • 分镜卡片状态机与重试、完善流程
  • 对话面板承载实时思考、工具轨迹与产物文件卡

创作画布

节点式创作编排，画布指令由服务端信箱转发

  • 节点执行与画布态持久化
  • 由主站的统一反向代理下发

移动端

随手查看与轻量编辑

  • 复用同一套接口与登录态
加密传输 · 流式响应
02
接入层
唯一对外入口，先鉴权再分流，长连接不缓冲

前端入口

主站与画布站静态资源托管，同一域名下两个应用

  • 接口请求统一反向代理到 API 网关
  • 流式响应关闭缓冲并放宽读超时，保证逐段可见
  • 单请求体积上限放宽，支持大文件上传
  • 提供健康检查端点供部署探活

API 网关 统一入口

统一入口 · JWT 鉴权 · 路由转发 · 跨系统令牌交换

智能体会话→Moon 智能体
资产库→项目库服务
画布指令→画布服务
认证与业务→分镜业务服务
  • 服务发现默认关闭，按直连地址路由，少一跳注册中心
鉴权通过后转发
03
业务服务层
产品数据的事实来源，三个服务各自持有边界

分镜业务服务 主后端

项目 · 分镜 · 认证 · 文件兼容接口

  • 项目草稿与生效状态、分镜增删改
  • 登录、令牌签发与跨系统令牌交换
  • 脚本 / 图片 / 视频生成的对外接口

项目库服务 统一资产库

全平台资产、文件夹、分组与标签的唯一归属

  • 上传、批量导入、媒体内容直出
  • 保留旧画布资产主键与只读兼容查询
  • 统一资产映射，避免多套资产表各说各话

画布服务

画布后端与浏览器命令信箱

  • 画布态与节点执行结果
  • 供智能体下发画布执行指令
创作任务下发 · 结果回流
04
智能编排层
全平台唯一的智能体执行面：一个编排服务 + 一个隔离执行面

Moon 智能体 唯一执行器

会话轮次、推理、工具调用与产物的编排中枢

  • 单一智能体运行时，旧编排器已退役
  • 规划模式 · 子智能体 · 长上下文压缩 · 异步工具
  • 一轮只允许一条有序事件通道，事件序号连续递增
  • 思考与正文逐段实时推送，不等到结束才显示
  • 人工确认即暂停、断点续跑；拒绝即终态，不再回灌模型
  • 六个生产技能 + 运行时技能仓库，系统提示词与工具元数据可版本化
  • 运行时状态与事件持久化，支持断线重放与补偿

沙箱执行面 独立常驻

代码与文件的真实执行环境，不碰宿主机路径

  • 常驻共享容器，按会话划分独立工作目录
  • 文件读写、目录列举、脚本执行三类工具
  • 非 root 运行 · 只读根文件系统 · 处理器与内存限额
  • 出站流量仅经代理并受域名白名单约束
  • 同会话严格串行，不同会话可并发
  • 产物目录是唯一真源，宿主机路径一律不作数
产物沉淀链路 · 每轮结束后自动执行
扫描产物目录→ 校验类型与大小→ 按内容哈希去重→ 上传对象存储→ 登记为平台资产→ 回写消息文件卡
模型调用与流式返回
05
模型能力层
上游密钥与协议差异全部下沉到这一层

统一大模型网关 全部模型调用经此

渠道管理 · 模型路由 · 参数 Schema · 调用日志 · 密钥加密

  • 文本、生图、图改图、视觉、视频统一转发
  • 按协议分发上游适配器，新增协议只增适配器不改编排
  • 模型参数能力枚举与默认值统一下发，供确认卡片联动选择
  • 上游密钥加密存储，业务侧不再持有厂商密钥
全部服务共用的持久化与支撑面
06
存储层
业务数据、运行时状态与最终产物分层归集

关系型数据库

业务数据与智能体运行时状态

  • 项目、分镜、资产、会话与轮次事件
  • 运行时上下文、检查点与工具审计

缓存

会话任务锁与热点缓存

  • 同一会话严格串行的锁语义
  • 开启持久化，重启不丢锁状态

对象存储

最终产物的唯一真源

  • 图片、视频、文档、表格与图表
  • 沙箱工作文件不作数，上传后才算交付

配置中心 可选

技能、全局提示词与工具元数据

  • 版本化发布，支持离线回退
  • 默认不参与统一栈，按需单起

自托管网页检索 旁路

智能体联网搜索的默认后端

  • 随栈启停，不依赖外部检索接口

离线语音识别 旁路

中文语音转写，供创作输入使用

  • 内网部署，不经公网
