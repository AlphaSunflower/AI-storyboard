编排状态机（bounded loop）

  • • INTENT 意图识别 → 需求澄清（手动循环，type=0 追问）→ HITL checkpoint 落库 → resume 续流 → EXECUTE 工具执行 → message_end
  • • MAX_STEPS=10 防死循环 · REVIEW 位预留（后续「循环直到完成目标」增强）
  • • 虚拟线程执行 · user 消息独立事务（REQUIRES_NEW）立即提交，失败保留

意图路由（4 链）

  • • aisplit：剧本优化 gate → 分镜方案 → 分镜 JSON → HITL 满意/不满意 → writeScenes 写库
  • • pic：有参考图 → 视觉模型改图方案 + HITL；无图 → LLM 提示词文生图自动完成（无 HITL）
  • • video：方案（视觉 / LLM）→ video_plan 卡片 → MiniMax 生成（轮询 ~2min）
  • • other：AgentAnswerService 流式回答（打字机）

关键设计

  • • checkpoint：一次性消费（pending→used 原子条件）+ 30min 过期；不存在/过期/已用均报错
  • • 结构化输出纯解析（BeanOutputConverter），不发 response_format，规避网关不兼容
  • • 首条消息 → 异步 AI 重命名标题，随 message_end 一次性推送 title；标题线程用条件更新防覆盖
