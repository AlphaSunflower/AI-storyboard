# 模型参数能力 + 默认值配置（OpenAI 契约全 API）与前端联动 — 实现计划 v2

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** 文本生成（chat/completions）、图像生成（images/generations + edits）、视频生成（videos）三类 API 的模型参数在网关统一配置：能力枚举（可选值/范围）+ 默认值（发送时默认携带），管理后台以**表单形式**填写保存，经 `/v1/models` 下发，驱动 AI 分镜前端参数下拉动态展示与默认预选（静态硬编码兜底）。

**Architecture:** 三层数据流——
1. 网关：`model_params` 表一行一模型（model_name UNIQUE），按类型分组列：text 存默认值（temperature/max_tokens/top_p）、image 存能力枚举+默认（n/sizes/qualities/styles）、video 存能力枚举+默认（durations/resolutions/aspectRatios）；管理后台路由表单内嵌「参数配置」表单区（按类型显示对应字段组）；`GET /v1/models` 每个模型带 `params` 对象（能力 + 默认值）
2. 后端：`GET /api/ai/models` 透传 `params`
3. 前端：生图/生视频面板参数下拉选项 = 当前模型 `params` 的能力枚举，**默认选中 = `params` 的默认值**；切换模型联动重置悬空值；未配置时回退静态 `IMAGE_SIZES`/`IMAGE_QUALITIES`/`VIDEO_PRESETS` 与 `DEFAULT_*` 默认值

**Tech Stack:** Spring Boot 4（网关+主后端）、PostgreSQL、原生 JS 管理后台（admin-ui）、React 19 + Zustand 5 主前端

## OpenAI 契约参数定义（model_params 列 ↔ 下发 params 对象）

```jsonc
// 下发 params 对象结构（/v1/models data[].params；未配置 → null）
{
  // text 类型（chat/completions 默认值，无能力枚举）
  "defaults": { "temperature": 0.7, "max_tokens": 1024, "top_p": 0.9 },

  // image 类型（images/generations + images/edits 共用，用户已确认）
  "n": { "min": 1, "max": 4, "default": 1 },
  "sizes": ["1024x1024", "1536x1024", "1024x1536"],  "sizeDefault": "1024x1024",
  "qualities": ["standard", "hd"],                  "qualityDefault": "hd",
  "styles": ["vivid", "natural"],                   "styleDefault": "vivid",

  // video 类型（videos 契约；MiniMax/Laozhang 差异由网关侧已有逻辑处理）
  "durations": [4, 6, 8],      "durationDefault": 6,
  "resolutions": ["768P", "2K"], "resolutionDefault": "768P",
  "aspectRatios": ["16:9", "9:16", "4:3", "1:1"],  "aspectRatioDefault": "16:9"
}
```

前端规则：下拉选项 = 枚举数组（缺失回退静态）；初始选中 = `xxxDefault`（缺失回退现有 `DEFAULT_*`/第一项）；`defaults`（文本）本次仅下发存储，前端不新增文本参数 UI（YAGNI，后端生成服务未来可用）。

## Proposed Approach

### 数据与契约

- **DB**：`model_params` 表（V5 migration）——一行一模型，按类型分组列（见 Task 1 SQL 全列）；`type` 冗余列；所有枚举列 TEXT 逗号分隔（规避 MP+PG 数组坑）
- **管理端点**：`ModelParamsController`——`GET /admin/model-params/{modelName}`（表单回显）、`PUT /admin/model-params`（按 model_name upsert，type 枚举/n 范围/nMax>=nMin 校验）
- **网关下发**：`GET /v1/models` 按 model_name 组装 `params`（能力枚举 + 默认值；无记录 → null）
- **管理入口**：admin-ui 路由表单内嵌「参数配置」区——**按路由 type 联动显示字段组**（text：temperature/max_tokens/top_p；image：n 范围+默认、sizes+默认、qualities+默认、styles+默认；video：durations+默认、resolutions+默认、aspectRatios+默认）；type 切换时表单组联动；保存路由时并行 upsert model_params
- **后端透传**：`AIController.fetchGatewayModels` 解析 `data[].params` 并入返回值 `{ value, label, params }`

### 前端联动

- **类型**：`config.ts` 定义 `ImageModelParams`（n{min,max,default}、sizes、sizeDefault、qualities、qualityDefault、styles、styleDefault）、`VideoModelParams`（durations、durationDefault、resolutions、resolutionDefault、aspectRatios、aspectRatioDefault）、`TextModelParams`（defaults）；`ModelOption.params` 联合类型
- **store**：模型 options 带解析后 params；新增 `imageN` 状态（默认取 params.n.default ?? 1）
- **生图面板**（LeftSidebar/ScriptInputPanel 同构）：
  - 尺寸下拉 = `params?.sizes?.length ? params.sizes : IMAGE_SIZES`；**默认选中 = `params?.sizeDefault` 在选项中 ? 它 : 现有 imageSize**
  - 质量下拉同理（`qualityDefault`）；「数量 n」控件仅 `params?.n` 存在时渲染，默认 `n.default`
  - 切换模型：选项集变化时悬空值重置为默认值/第一项
- **生视频面板**（VideoPresetSelector）：durations×aspectRatios 组合（回退 VIDEO_PRESETS）；默认 preset = `durationDefault`+`aspectRatioDefault` 匹配项（匹配不到取第一个）；`resolutions` 不驱动 UI（后端统一 768P）
- **完善弹窗**（ImageRefineModal/VideoRefineModal）：保持只有 model/prompt（YAGNI，用户未选弹窗联动）

ModelParams mp = paramsMap.get(r.getModelName());
Map<String, Object> params = null;
if (mp != null) {
    params = new LinkedHashMap<>();
    // text 默认值对象（任一非空才放）
    Map<String, Object> defaults = new LinkedHashMap<>();
    if (mp.getTemperature() != null) defaults.put("temperature", Double.parseDouble(mp.getTemperature()));
    if (mp.getMaxTokens() != null) defaults.put("max_tokens", mp.getMaxTokens());
    if (mp.getTopP() != null) defaults.put("top_p", Double.parseDouble(mp.getTopP()));

    // image：n 范围+默认

        Map<String, Object> n = new LinkedHashMap<>();

        if (mp.getNMax() != null) n.put("max", mp.getNMax());
        if (mp.getNDefault() != null) n.put("default", mp.getNDefault());
        params.put("n", n);
    }
    // 枚举 + 默认（逗号分隔 → 数组；空跳过）：
    putCsvList(params, "sizes", mp.getSizes());         putDefault(params, "sizeDefault", mp.getSizeDefault());
    putCsvList(params, "qualities", mp.getQualities()); putDefault(params, "qualityDefault", mp.getQualityDefault());
    putCsvList(params, "styles", mp.getStyles());       putDefault(params, "styleDefault", mp.getStyleDefault());
    // video：

    putCsvList(params, "resolutions", mp.getResolutions());  putDefault(params, "resolutionDefault", mp.getResolutionDefault());
    putCsvList(params, "aspectRatios", mp.getAspectRatios()); putDefault(params, "aspectRatioDefault", mp.getAspectRatioDefault());
    if (params.isEmpty()) params = null;
}
m.put("params", params);

## Risks / Tradeoffs / Open Questions

- **R1（需验证）**：主后端 `GenerateImageRequest` 是否已有 `n` 字段——实现 Task 9 前先 grep；没有则 DTO + ImageGenerationService 加透传（默认 1 兼容）
- **R2**：`/v1/models` 带 OpenAI 非标准扩展字段 `params`——客户端忽略多余字段，兼容
- **R3**：表格方案 schema 固定——新增参数类型需加列（migration）；三类参数集已明确（text/image/video），可接受。枚举列 TEXT 逗号分隔规避 MP+PG 数组坑；校验在 Controller（type 枚举、nMin<=nMax）
- **R4**：参数挂模型级（model_name 唯一）——同模型多渠道共享；/v1/models 去重保留首个路由，按 model_name 关联
- **R5**：`resolutions` 不驱动视频 UI（后端统一 768P）——列保留，UI 不渲染
- **R6（已定）**：图生图（images/edits）与文生图共用 image 参数——表结构无 api 维度；multipart 差异由既有 ImageEditService 处理
- **R7**：文本参数（temperature/max_tokens/top_p）本次仅配置存储 + 下发（`params.defaults`），前端文本生成不新增 UI（YAGNI）——后端生成服务未来可读默认值
- **OQ1**：n 是否展示在 SceneCard 生成/重试流程——本计划仅编辑面板，生成流程传 store 的 imageN
- **OQ2**：完善弹窗参数控件——用户已选共用方案未选弹窗联动，弹窗保持 model/prompt
- **OQ3（v2 已改）**：管理表单按 type 分组联动显隐（用户需求「对应所有 api 提供解决方案」）——text/image/video 各自字段组，type 切换重建
