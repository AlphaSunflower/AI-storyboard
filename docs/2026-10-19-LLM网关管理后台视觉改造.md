# LLM 网关管理后台视觉改造

> 日期：2026-10-19
> 目标：把「温暖编辑风」收敛成内部运维控制台，优先扫描、密度、状态与一致性，而不是营销页表达。

## Design read

- 页面类型：内部管理控制台（Operate mode），不是 landing page / portfolio。
- 用户：网关运维、模型接入、渠道配置人员。
- 视觉方向：中性石色底、石墨字、单一氧化红强调色；系统无衬线 + 等宽数字；去掉装饰性编号和衬线标题。

## 关键改动

### 1. 外壳与导航

- 侧栏 224px，桌面端 sticky，长表格滚动时导航不丢。
- 移除 `01 / 02` 编号和 `CONTROL PLANE` 眉标，导航只保留动作名。
- 分组改为「运行 / 系统」，active 使用白色浮层，不再用粗色左边条。
- 移动端（≤860px）侧栏变成顶部横向导航，保留文字标签；内容回到单列。

### 2. 页面头与筛选

- 标题与筛选项同一行：搜索、生成类型、渠道。
- 筛选去掉胶囊容器，三个控件独立、等高 32px。
- 所有 `select` 改为自定义 chevron（`appearance:none` + CSS 背景），修复原生箭头压住文字、下拉边缘被裁剪的问题。
- `aria-label` 补全搜索、类型、渠道筛选。

### 3. 色彩与排版

- token：canvas `#f2f3f0`、card `#fcfcfa`、ink `#1b1c1a`、accent `#a9543c`。
- 标题统一系统无衬线，去掉 serif display；数字表头/统计值使用 tabular-nums。
- 对比度：占位文字 `#64675f`，主按钮白字对 `#a9543c` 为 5.22:1。
- 统一 6px 控件圆角 / 10px 卡片圆角，去掉重阴影和渐变装饰。

### 4. 表格与工作台

- 表头 sticky，行高收紧到 9px/12px padding，hover 使用浅石色。
- 模型配置：顶部横向模型列表 + 搜索/类型/渠道筛选；参数表在 ≤1800px 时独占整行，右侧预览/试运行移到下方，避免最后几列被挤掉。
- 日志表在视口内滚动，表头保持可见。
- 模型路由弹窗只保留绑定字段；缺失模型 Schema 时显示黄色警告和「去模型配置」按钮。

### 5. 交互与状态

- 统一 `:focus-visible` 环，输入框只用一层 focus ring，避免双重边框。
- 按钮保留 hover/active/disabled；toast 去掉 4px 色条，改用边框与底色区分成功/错误。
- 模态框加宽到 760px，头部/底部固定，正文独立滚动。

### 6. 响应式

- ≤1800px：模型工作台右侧栏移到参数表下方。
- ≤1100px：内容 padding 缩小，工作台单列。
- ≤860px：顶部导航、标题与操作同排、筛选占满一行。
- ≤520px：操作按钮换行，筛选控件全宽。
